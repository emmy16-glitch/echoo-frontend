# Echoo onboarding responsive audit

This pass keeps the first onboarding phase consistent across:

- wide desktop (1440px+)
- common laptop widths (1280px and 1366px)
- short laptop heights (680–820px)
- compact desktop/tablet (761–1120px)
- phones (360–760px)
- coarse-pointer devices that request a wider desktop-style viewport

The first phase is Account → Profile → Role. Role-specific onboarding continues after this phase.
